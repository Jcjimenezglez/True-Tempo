The search is the diagnosis

People type “why can't I focus” when the afternoon already failed. They are not looking for a TED Talk. They want a reason that is not “you are broken,” and a next step that fits inside one sitting.

Keywords Everywhere shows about 1,900 US monthly searches for that exact phrase. Adjacent queries—“can't focus on work,” “how to stop getting distracted”—are the same wound with different wording.

Usually it is not one cause

Focus fails when three things stack: an unclear next action, an environment that keeps pinging you, and a work block with no start or stop. Superfocus is built for that stack: name the task, start a timer, optionally add a cassette so you are not also hunting YouTube.

  • Unclear task — “work on the project” is not a session. “Write the intro paragraph” is.
  • Open loops — Slack, phone, extra tabs. Each one is a vote against the block.
  • No container — without a countdown, “I'll start in a minute” never expires.

What Superfocus actually changes

It does not fix sleep, diet, or undiagnosed ADHD. It removes the negotiation around this hour. Open the free timer, pick Sprint if starting feels impossible, Pomodoro if you can do 25, Flow if you already have momentum. Optional rain or lofi so the room is not the loudest thing in your head.

A 20-minute experiment

  1. Write one outcome on the task line. One.
  2. Put the phone in another room or at least face down.
  3. Start Sprint (15) or Pomodoro (25). Do not optimize the preset first.
  4. When it ends, take the break. Do not “just finish this email.”

If you complete two of those in a row, the problem was not mystery brain fog. It was missing structure. If you still cannot start after Sprint, the task is too big—split it again.

When to look past the timer

Chronic inability to focus, sudden change from your baseline, or focus that only returns with substances is a health question, not an app question. A timer is a tool. It is not a diagnosis.
